# Flight Atlas Dev (локальный тестовый режим)

Эта ветка предназначена для предварительного просмотра. Она не публикует релизы.

## Первый запуск на Windows
1. Один раз клонируйте ветку `flight-atlas-dev` в постоянную папку (например, `C:\\FlightAtlasDev`).
2. Установите Node.js LTS и выполните в папке проекта `npm install`.
3. Запускайте `npm run dev` — откроется отдельное окно Electron.

Для следующего запуска достаточно `npm run dev`. При изменении исходников потребуется перезапуск приложения (автоматическая горячая перезагрузка ещё не настроена).

В режиме Dev используется отдельная папка пользовательских данных `Flight Atlas Dev`, а обновления из GitHub Releases отключены. Обычная установленная версия не меняется.

**Важно:** ChatGPT не имеет автоматического доступа к этой локальной папке. Для правок без загрузки в GitHub потребуется подключённая среда разработки/доступ к файлам. Не сливайте ветку Dev в main до проверки.
