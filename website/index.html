ВОПРОСЫ И ОТВЕТЫ

Нужно знать

Коротко о платформе, обновлениях и бесплатной загрузке.

Flight Atlas бесплатный?

Да, текущая сборка приложения распространяется бесплатно через публичный репозиторий релизов.

Где скачать последнюю версию?

Нажми «Скачать для Windows» — сайт найдёт актуальный установщик в GitHub Releases. Если GitHub API временно недоступен, откроется страница последнего релиза.

Можно открыть Flight Atlas в браузере?

Пока эта страница — сайт проекта, а не полноценная браузерная версия Electron-приложения. Для работы с самим атласом установи версию для Windows.

Как обновляется приложение?

Новые версии публикуются в GitHub Releases. В десктопном приложении предусмотрено обновление через кнопку Update.
